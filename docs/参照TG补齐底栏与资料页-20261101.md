2. **打开对话时隐藏底栏**：手机上进入聊天后输入栏就在底部；官方聊天页也是全屏 push。

### 2.3 验收中发现并修掉的 3 个真问题

1. **系统返回键在对话页直接退出应用**：窄屏对话页没有 `PopScope`，按返回键等于 pop 掉唯一路由。修：`PopScope(canPop: _showChatList, onPopInvokedWithResult: …)`，并把 `onBack` 统一到 `_backToChatList()`（同时通知外壳底栏回来）。
2. **联系人行副标题重复名字**：服务端 `remark` 经常等于 `nick`，原条件 `remark.isNotEmpty && nick.isNotEmpty` 就显昵称。修：`contacts_page.dart:86-89` 加 `&& remark != nick`，否则显 `QQ <uin>`。
3. **资料页「备注」与昵称重复**：`friend_profile_page.dart:110` 改 `remark.isEmpty || remark == nick ? '未设置' : remark`。

## 6. 已知限制

- 好友头像用公开 CDN 接口（`https://q1.qlogo.cn/g?b=qq&nk=<uin>&s=100`），不在协议包里，换号/断网时按 `TelegramAvatar` 的重试规则退化首字母。
- `selfNickname` 只能从群成员名单里「认出自己」，没加过任何群时「我的」页只显示 QQ 号。
- 联系人页数据依赖登录后 `fetchFriendList`；未上线且无缓存时显示空态引导，不假装有数据。
