## 1. 为什么要做这件事

P2 实验（`docs/图片直链刷新实验-P2结论-20261031.md`）已经证明：**重拉历史不会重签 rkey**，同一张图的 `download?...&rkey=` 逐字节不变，而且部分老图会被降级成无签名的 `gchatpic_new/0/0-0-<MD5>/0`（404）。
真机 21 张唯一图里 10 张签名直链全部 400 `-5503007 download url has expired`，8 张 md5 兜底形态 6 张 404。

⇒ 客户端**无法**自己续期、无法自造 rkey（`-5503010 invalid rkey`）、改 spec 也无效（`-5503037`）。
**唯一出路是走官方自己的补链通道**：`ImgStore.GroupPicDown`（WUP/protobuf，不是 highway 大通道）。

3. 按**图片规格**选 url_flag / url_type：
   - 缩略 `65537` → flag 1，type 2

   - 原图 `131075` → flag 2，type 4
4. 回包 `RspBody.rpt_msg_getimg_url_rsp`：`uint32_result == 0` 时按同一张规格取 para —— 缩略 `bytes_thumb_down_para`、大图 `bytes_big_down_para`、原图 `bytes_original_down_para`；另给 `rpt_uint32_down_ip` / `rpt_uint32_down_port` / `bytes_down_domain` / `uint32_https_url_flag` / `rpt_msg_down_ip6`。

## 3. 已落地的内核实现（`lib/kernel/wlogin8/qq8_image.dart`）

L2 纯 Dart，无 Flutter 依赖，和 `Qq8ImageUp` 放同一文件：

```dart
class Qq8PicDownReply {
  final int result; final String failMsg; final String md5Hex;
  final Uint8List? thumbPara, originalPara, bigPara, bigThumbPara;
  final List<String> domains; final List<String> ips; final List<int> ports;
  final int httpsFlag;
  bool get ok => result == 0 && (thumbPara != null || originalPara != null || bigPara != null || bigThumbPara != null);
}

abstract final class Qq8ImageDown {
  static const cmdGroupPicDown = 'ImgStore.GroupPicDown';
  static const picTypeThumb = 65537, picTypeBig = 1, picTypeOriginal = 131075;
  static (int flag, int type) urlFlagTypeOf(int picType);
  static Uint8List buildGroupPicDownBody({required int gid, required int uin, required List<String> md5HexList,
      int picType = picTypeOriginal, List<int>? fileIds, List<int>? picUpTimestamps,
      int netType = 6, int buType = 1, int transferType = 0, String buildVer = '8.2.11.0153f87a'});
  static List<Qq8PicDownReply> parseGroupPicDownResponse(Uint8List payload);
}
```
