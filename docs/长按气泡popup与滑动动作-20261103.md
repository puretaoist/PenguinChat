# 长按气泡 popup / 长按多选 / 会话滑动归档与静音（2026-11-03）

对齐 Telegram 13.0.3 的两类交互，补掉 `docs/前端对齐TG-会话列表与聊天页-20261031.md` 里最后两条「未实现」：

1. **单击气泡 → 气泡旁浮层菜单（popup）**，不再是底部 ActionSheet；
2. **长按气泡 → 直接进多选（action mode）**，不再先弹菜单；
3. **会话列表左右滑动 → 归档 / 静音**。

## 1. 单击气泡：气泡旁 popup

- 新文件 `lib/ui/widgets/message_action_popup.dart`
  - `Future<void> showMessageActionPopup(BuildContext context, {required Rect anchor, required bool outgoing, required List<ActionSheetItem> items})`
  - 常量为 TG 的实测值：宽 200、行高 48、圆角 12、图标列 43（左内边距 12 + 图标 20 + 间隔 11）、文字 15sp。
  - 定位：对方气泡（`outgoing == false`）→ 菜单左缘 = `anchor.right + 8`；自己气泡 → 菜单右缘 = `anchor.left - 8`；
    再 `clamp` 到视口内（左右 8、上下 16），保证贴边消息也能完整显示。
  - 动画：200ms `easeOutCubic`，从贴着气泡的那条边 `Fade + Scale` 展开；关闭是反放动画、动画结束才摘 `OverlayEntry`、最后才执行动作（点错不会先执行再关）。
  - 遮罩：`Colors.black.withValues(alpha: 0.20)`，key `message-popup-barrier`，点遮罩只关闭、不执行任何项。
- `lib/ui/widgets/message_actions.dart`：原来的 `_items(...)` 提升为公开的
  `MessageActionsSheet.itemsFor(context, {required ChatMessage message, required bool canRecall, bool includeSelect = true, ...})`，
  底部弹层与 popup 共用同一份清单；popup 传 `includeSelect: false`（多选是长按的入口，不是菜单项）。

### 1.1 锚点必须取「气泡自己」的 RenderBox（本轮真 bug）

第一版把 `Builder` 包在 `GestureDetector` 外层，用它 `findRenderObject()` 当锚点。`MessageBubble` 的根是
`Padding(child: Row(...))`，`Row` 撑满整行，于是锚点的宽度是**整行**宽度：

- 表现：点群聊里一条左对齐的短气泡，菜单被顶到**屏幕最右边**（真机实测菜单 x 从 1332 起，气泡右缘约 610）；
- 记录：`C:/Users/Administrator/.dsh/workspace/_popup.png`（错误定位的截图，保留作对照）。

修法：`lib/ui/widgets/message_bubble.dart` 新增

```dart
final void Function(RenderBox box)? onBubbleBox;
final ValueChanged<RenderBox>? onBubbleBoxGone;
```

并用 `BubbleBoxReporter extends SingleChildRenderObjectWidget`（`_BubbleBoxRender extends RenderProxyBox`）
把**真正的气泡**（`ConstrainedBox`，不含左右各 8dp 行内留白）的 RenderBox 交出去：`attach()` 时上抛，
`detach()` 时连同自己一起回调，调用方按**身份**删掉，不当心删到同名 id 的新气泡。

`lib/ui/pages/home_page.dart` 用 `Map<String, RenderBox> _bubbleBoxes` 存这份引用，
`_showMessagePopup` 在**点击那一刻**才 `localToGlobal(Offset.zero) & size`：

- 存 box 而不是 Rect：Rect 是布局快照，滚动（`RenderSliver` 改 offset 不触发子级 `performLayout`）之后 Rect 会过期，菜单会飘在旧位置；
- 依次回退：气泡 box → 外层整行 box → 屏幕中心，任何一步拿不到都照弹菜单，不因定位失败而丢功能。

## 2. 长按气泡：直接进多选

- `home_page.dart`：`onLongPress: () => _enterMessageSelection(m)`；`HapticFeedback.mediumImpact()`；
  单次上限 100 条（TG `ActionMode` 的常量），超了给「一次最多选 100 条」而不是静默失败。
- 多选模式下单击气泡 = 勾选/取消勾选（`onTap` 分流由 `_selecting` 判断）。
- 局限（诚实记录）：**TG 底部那条 Reply / Forward 圆形按钮条没有做**，目前多选只有页面已有的顶部选择栏（计数 + 取消 + 删除等）。
  这是与本轮「抄 TG 交互」目标的已知差距，不算完成。

## 3. 会话列表：滑动归档 / 静音

- `lib/ui/widgets/chat_list_panel.dart` 构造新增可选回调
  `Future<void> Function(Chat chat)? onArchiveChat`、`Future<void> Function(Chat chat)? onToggleMuteChat`。
- 每行包一层 `Dismissible`（key `ValueKey('swipe-<chatId>')`）：左滑（`endToStart`）→ 归档，右滑（`startToEnd`）→ 静音/取消静音，
  两侧背景是带图标和文案的纯色块。
- **`confirmDismiss` 一律返回 `false`**：动作由 store 改状态、列表成员由 store 变更驱动重建。
  返回 `true` 会让 `Dismissible` 自己把子级移出树，随后 store 重建又发现「A dismissed Dismissible widget is still part of the tree」而崩。
- 两个回调都为 null 时**不挂** `Dismissible`（列表只读场景不该有手势）。
