## 3. 输入栏（chat_input_bar.dart）

- 表情键移到最左（TG ChatActivityEnterView 的顺序），附件只剩一个回形针。
- 回形针点开底部 ActionSheet：**发送图片 / 发送文件**（key `attach-file` / `attach-local-file` 挂在菜单项上，原来并排两个 IconButton 撤销）。
- 右侧按钮随输入内容切换：有字 = 纸飞机（accent 底、白图标，可点）；空输入 = 麦克风 `Icons.mic_none`（灰底、onTap 为 null）——假发送键会让人以为已经发出去。
