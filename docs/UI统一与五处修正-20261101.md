### 踩到的问题（已修）
「我的」页首次安装后昵称仍显示 uin、标题与副标题重复。根因不是改法本身，而是**触发时机**：HomeShell 用 IndexedStack，四个 Tab 在冷启动那一刻就全部 build，此时还没上线，`ensureSelfNickname()` 在服务层被 `if (!isOnline || _session == null) return;` 直接挡回，之后没有第二次机会。
改法：把触发点从 `initState` 抬到 `build()`（服务层自带「每账号只试一次 / 未上线直接返回」两道闸门，重复调用零成本），并把副标题改成 `if (hasNickname)` 才渲染，避免与标题重复。复测即 PASS。

日志佐证（`/data/user/0/com.puretaoist31.penguinchat/files/logs/qqclient-2026-11-01.log`）：12:37:46 `群列表：1/1 个群（result=0）`；改后进入「我的」页即触发群列表 + 群成员并认出自己。
