## 2. 为什么选 SILK 而不是 AMR

官方 QQ 8.2.11 现场配置（真机 `shared_prefs/RecordParams_*.xml`）：
`SilkCfg=1|2|16000|1|2|16000` ⇒ **16 kHz / 单声道 / 16 kbps SILK**。
腾讯 `libcodecsilk.so` 把 Skype 官方 SILK SDK 的 C API 原样导出
（`SKP_Silk_SDK_*`，SDK 版本 1.0.9.6），所以我们**自编译开源 SILK v3**、
Dart 走 FFI 调用即可字节级兼容，**不打包也不依赖腾讯的 so**。

不用 AMR 的原因：AMR 只是「能播就行」的降级方案，服务端是否接受未验证；
而 SILK 是官方格式，收到什么就能播什么。

## 3. 关键接口

```dart
// infra（纯 Dart 抽象）
abstract class VoiceEngine { play/pause/resume/stop/seek + Stream<VoiceEngineEvent> events }
abstract class VoicePreparer { Future<PreparedVoice?> prepare(String localPath); }
class PreparedVoice { String pcmPath; int sampleRate; int durationMs; List<double> waveform; }

// ui（实现）
class SilkVoicePreparer implements VoicePreparer   // SILK→PCM，写 <tmp>/<名>.pcm
class BridgeVoiceEngine implements VoiceEngine     // 包 AudioBridge
class VoicePlaybackController extends ChangeNotifier { toggle({key, seconds, ensurePath}) ... }
```

装配点：`lib/ui/pages/app_bootstrap.dart` 的 `_initVoice()`（postFrame，
只装配不预热；失败只 `_log.w`，绝不阻塞启动）。

## 6. 顺带修掉的两个显示 bug

真机语音消息的第一个 `Elem` 解出来是**空 map**。旧代码给空元素写了
`[不支持显示的消息]` 占位，于是：

* 语音气泡上面多一行 **`[unknown]`**；
* 会话列表预览变成 **`[不支持显示的消息][语音]`**。

修法：
* `lib/kernel/wlogin8/qq8_elem.dart`：空 Elem 只记 `kinds('empty')`，
  **不产生文本、不产生段**；
* `lib/client_api/chat_store.dart`：读取历史时把 `UnknownSegment(elem == 'empty')`
  一并丢掉（与既有的 field=9 同处理）；会话预览再擦一次旧的前缀。
* 自测：`tool/qq8_elem_scan_selftest.dart` 新增 3 项「空 Elem 不产生可见内容」→ 33 项全过。

## 7. 明确没做（下一批）

* **录音与发送（V2）**：`AudioBridge` 已具备 `recordStart/recordStop`
  （写 cacheDir/penguinchat_rec_*.pcm），但**没有 UI**，且
  `AndroidManifest.xml` 虽已加 `RECORD_AUDIO` 声明，**运行时权限申请未做**。
  发送还需要 `cmd0x346`（APPLY_UPLOAD/APPLY_DOWNLOAD/回执）与
  `RichText.ptt`（msgtype=-2002）的组包。
* **私聊图片**同理未接 `LongConn.OffPicDown`（与本批无关，见 C106）。
* AMR 文件不播（返回 `无法解码这条语音`，不假装成功）。
* iOS/桌面：`_initVoice()` 直接 return（只有 Android 有 AudioBridge）。
* 波形：协议里没有波形字段，本地按解码 PCM 的峰值算（30 柱）。
