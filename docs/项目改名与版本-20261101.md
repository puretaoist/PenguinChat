# 项目改名与版本号（2026-11-01）

## 1. 改了什么

| 项 | 旧 | 新 |
| --- | --- | --- |
| Dart 包名 / pubspec `name` | `qqclient` | `penguinchat` |
| Android `namespace` / `applicationId` | `com.example.qqclient` | `com.puretaoist31.penguinchat` |
| Kotlin 源码目录与 `package` | `kotlin/com/example/qqclient/` | `kotlin/com/puretaoist31/penguinchat/` |
| 应用显示名（manifest `android:label`） | `qqclient` | `PenguinChat` |
| 版本号（pubspec `version`） | `0.1.0+1` | `1.0.0+1` |
| 实验包后缀 | `com.example.qqclient.test` | `com.puretaoist31.penguinchat.test` |

顺带把应用**自己持有**的标识一起改齐，避免「包名是新的、日志里还叫旧名字」：

- MethodChannel：`qqclient/keepalive`、`qqclient/device`、`qqclient/notify`
  → `penguinchat/keepalive`、`penguinchat/device`、`penguinchat/notify`
  （Kotlin 与 Dart 两侧**必须同一次提交改完**，只改一边的表现是全部平台调用抛
  `MissingPluginException`，而且是运行期才炸，编译期看不出来）。
- 通知渠道 id：`qqclient.keepalive` / `qqclient.messages` /
  `qqclient.messages.group` → `penguinchat.*`。旧渠道随旧包卸载一起消失，
  不需要迁移。
- HTTP User-Agent：`qqclient/0.1` → `penguinchat/1.0`。
- 84 个 `import 'package:qqclient/...'` → `package:penguinchat/...`。

## 2. 刻意**没有**改的

| 项 | 为什么留 |
| --- | --- |
| 日志文件名前缀 `qqclient-YYYY-MM-DD.log` | 磁盘上的存储键。改了以后历史日志与新日志对不上，而排障脚本/文档全是按这个前缀找文件 |
| `qqclient-attempts.json`（限流状态） | 同上；改名等于把用户已有的冷却历史丢掉 |
| `<Temp>/qqclient` 回退目录 | 同上 |
| 签名文件 `android/app/qqclient.p12` | 它是**证书文件**，改文件名不改变证书本身；改路径只会给 CI/本机各留一份不一致的配置 |

这些是内部存储键，不出现在界面上；哪天真要改，应该走一次性迁移而不是就地重命名。

## 3. 影响（重要）

`applicationId` 变了就是**另一个应用**：

- 旧包 `com.example.qqclient` 与新包可以同时装在机器上，互不干扰；
- 新包**没有**旧包的本地数据 —— 票据（`files/qq8/qq8-token-*.json`）、会话
  （`files/accounts/<uin>/`）、日志、`ui_prefs.json`、通知渠道设置全部是
  按 `/data/data/<applicationId>/` 隔离的；
- 所以装上之后需要**重新登录一次**（密码/短信/扫码），之后冷启动照样免验证。

本机迁移做法（仅当设备有 root、且想保住旧票据时）：

```bash
adb shell su -c 'cp -a /data/data/com.example.qqclient/files/. /data/data/com.puretaoist31.penguinchat/files/'
adb shell su -c 'chown -R $(stat -c %u:%g /data/data/com.puretaoist31.penguinchat) /data/data/com.puretaoist31.penguinchat/files'
```

拷贝前先启动一次新包，让 Android 把 `/data/data/com.puretaoist31.penguinchat` 建出来；
拷贝要在新包**未运行**时做，否则会与正在写的 jsonl 打架。

## 4. 验证

- `dart analyze lib` → **No issues found!**
- `flutter test` → **225 All tests passed**；`tool/run_all_selftests.sh` → **pass=55 fail=0**
- `bash scripts/build-local.sh release` → `app-arm64-v8a-release.apk` 21,126,695 字节（2026-11-01 08:46）
- 真机（HA2CSJR5 / 25091RP04C / Android 16）：
  - `adb install -r` 得到新包 `com.puretaoist31.penguinchat`，与旧包 `com.example.qqclient` 并存；
  - `dumpsys package` → `versionName=1.0.0`、`versionCode=2001`
    （2001 = 拆 ABI 包自动加的 2*1000 + pubspec 的 1，属正常）；
  - 按第 3 节的 `su cp -a` 把旧包 `files/` 搬过来后冷启动**直接免验证上线**：
    日志 `设备采集: 构建=git:d793d31 @2026-11-01T08:45:07` →
    `会话预览: uin=… 会话数=4` → `已上线 uin=…`（08:50:35）→
    `协议线已上线 … 数据根=/data/user/0/com.puretaoist31.penguinchat/files/accounts/…`，
    会话列表 4 条、头像与摘要正常，拉新消息/群历史照常。
  - 说明 MethodChannel 改名没有断：设备采集（`penguinchat/device`）、
    保活（`penguinchat/keepalive`）、通知（`penguinchat/notify`）都还通，
    否则第一次启动就会在设备信息采集那一步报 MissingPluginException。

## 5. 遗留

- 旧包 `com.example.qqclient` **仍然装着**（数据也在），确认新包没问题后可以
  `adb uninstall com.example.qqclient` 清掉；卸载前想留证据就先 pull 日志。
- 历史文档（`docs/*-202610xx.md`）里的 `com.example.qqclient` 与
  `package:qqclient/` 一律**不回改**：它们记录的是当时的现场。只有操作性文档
  （`CI-BUILD.md`、`tool/cdp_captcha.mjs`、`scripts/*.sh`）跟着改了。
