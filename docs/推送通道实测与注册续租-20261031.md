## 3. 机制（官方出处）

**注册 = 推送会话的周期续租**
- `msf/core/push/e.java:104-105`：`SvcReqRegister.timeStamp = aVar.k.timeStamp`、`iLargeSeq = aVar.k.iLargeSeq`（上次应答给的值，必须回送）。
- `e.java:203-240`：解析 `SvcRespRegister`，`cReplyCode(tag2)==0` 才算成功，成功才取 `uClientBatteryGetInterval(tag18)`；`timeStamp(tag8)`/`iLargeSeq(tag13)` 存进后续注册。
- `e.java:314-327`：用 `iHelloInterval(tag12)` 设 `this.f.C = iHelloInterval*1000` 并排下一次注册（默认 300s，`g.java:665-670`）。
- `g.java:604-615`：收到 `StatSvc.QueryHB` → 立即重新注册（服务端"催租"信号）。

**推送派发与消息通道**
- `g.java:642-657`：按 `aVar.m.cmds` 白名单派发；`ConfigPushSvc` 例外。
- `MessageHandler.java:2600-2634`：`MessageSvc.PushNotify` → `RequestPushNotify`，`wGeneralFlag & 8` 是子账号，`ping_flag==1` 才回执，其余情况交给 `a(fromServiceMsg, obj)` 走消息处理。
- oicq 对照：`listeners.ts:13-40` 的 `pushNotifyListener` 只按 `nested[5]` 分派到 `pbGetMsg` / 群系统消息 / 好友系统消息，**没有任何回执**。
