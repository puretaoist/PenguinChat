对应用户要求：「完善 ui 设计，动画，设置界面」。本轮只动表现层（L4），
不碰协议线与数据层。

## 1. 设置页（lib/ui/pages/settings_page.dart）

| 项 | 改动 | 依据 |
| --- | --- | --- |
| 账号卡 | 头像 52→56、名字 16→18、**整卡可点**（进 `Qq8ConnectPage`）、右侧 chevron、在线绿点、连接时挂状态胶囊 | TG 设置页顶部是 EditProfile 入口（`ProfileActivity`），整块可点 |
| 分组 | 「外观/消息」重排为「通用/消息/数据/连接/关于」，组标题保持 40 高 14 bold accent | `HeaderCell.java`:44/49/94-95 |
| 行 | 可点行**自动带 chevron**（`TgListTile.showChevron`，默认 `onTap != null`）；显式 `trailing` 优先 | TG `TextCell` 的 chevron 是列表行为，不是每处手写 |
| 页脚 | 底部居中 12sp 灰字「QQ Client · 自实现协议线路仅供学习用途」 | TG 设置页底部版本行同位置 |
| 入场 | 六组**错落淡入 + 12dp 上浮**，共用一条 520ms 时间线，每组 Interval 起点差 0.1 | 无官方对应（TG 用 ripple），属自加的轻量动效 |

关键实现点：
- 页面从 `ConsumerWidget` 改为 `ConsumerStatefulWidget`，用
  `SingleTickerProviderStateMixin` 持一条 `AnimationController`。
  **动画必须是有限时长**（520ms 后 forward 完成），否则
  `pumpAndSettle` 永久等不到静止、widget 测试直接超时。
- `_enter(index, child)`：`FadeTransition` + `Transform.translate(0, 12*(1-v))`，
  curve `Interval(start, min(start+0.55,1), easeOutCubic)`。
- 首帧就会显示（`..forward()` 在 initState），不做「先透明再出现」的延迟，
  避免弱机首帧空白。

## 2. 按压反馈（lib/ui/widgets/pressable_scale.dart，新增）

`PressableScale`：按下缩到 0.97 / 110ms 回弹。

- **用 `Listener` 而不是 `GestureDetector`**：它要套在已经有
  `onTap`/`onLongPress` 的组件外面（气泡），`GestureDetector` 会进手势
  竞技场，轻则长按失效、重则点击被吃；`Listener` 只旁听指针事件，
  不影响命中测试与内层手势。
- 已接：消息气泡（`lib/ui/pages/home_page.dart` 的 itemBuilder，
  套在 `MessageBubble` 外、`GestureDetector` 内）、设置页账号卡。
- 未接会话列表行：那行已有 `AnimatedContainer` 140ms 的选中/置顶底色过渡，
  再叠缩放会像「按扁」。

## 3. 列表组件（lib/ui/widgets/telegram_list_item.dart）

`TgListTile` 新增 `bool? showChevron`：
- `null`（默认）= 自动：`onTap != null` 且没给 `trailing` 时画
  `Icons.chevron_right`（20 / `textMuted`）；
- `false` = 强制不画（「断开连接」这类危险动作，箭头会暗示"进入下一页"）；
- 给了 `trailing`（Switch 等）时永远不画箭头。
